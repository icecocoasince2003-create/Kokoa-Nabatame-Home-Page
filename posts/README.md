# 記事（ブログ）の書き方

このフォルダに Markdown ファイル（`.md`）を 1 つ追加するだけで、記事が増えます。
プログラムを書き換える必要はありません。

## 新しい記事を追加する手順

1. このフォルダ（`posts/`）に新しいファイルを作る
   - ファイル名は `日付-英語のメモ.md` の形がおすすめ（例：`2026-07-01-conference.md`）
   - ファイル名がそのまま記事ページの URL（`/blog/2026-07-01-conference`）になります
2. 下の「テンプレート」をコピーして中身を書く
3. 保存すれば、トップページと `/blog` に自動で表示されます

## テンプレート

```markdown
---
title: ここに記事のタイトル
date: 2026-07-01
type: 発表
place: 会場や場所（無ければ空のままでOK）
url: https://関連リンク（無ければ空のままでOK）
---

ここに本文を書きます。空行で段落が分かれます。

- 箇条書きも使えます
- **太字** や [リンク](https://example.com) も書けます
```

## 各項目の説明

| 項目 | 説明 |
| --- | --- |
| `title` | 記事のタイトル（必須） |
| `date` | 日付。`YYYY-MM-DD` の形式（必須）。新しい順に並びます |
| `type` | 種別。下のいずれかを選ぶと色付きバッジが付きます |
| `place` | 場所・会場（任意。不要なら空でOK） |
| `url` | 関連リンク（任意。不要なら空でOK） |

### `type` に使える種別

`学会参加` / `研究会参加` / `発表` / `論文` / `受賞` / `イベント` / `その他`

---

本文は Markdown で書けます。見出し（`##`）、箇条書き、リンク、太字などがそのまま反映されます。
